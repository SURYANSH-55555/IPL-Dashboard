# IPL Dashboard Analysis

Interactive IPL Dashboard Analysis developed in Microsoft Excel as part of a task assigned by the Analytics and Consulting Club, NIT Rourkela.

## Project Overview

This dashboard provides season-wise IPL insights using interactive visualizations, KPI cards, pivot charts, and slicers. The project focuses on analyzing team performances, toss decisions, venues, and player statistics across IPL seasons.

---

## Features

- Season-wise dashboard filtering
- Interactive slicers
- KPI Cards
- Toss decision analysis
- Team performance comparison
- Venue-wise match analysis
- Player of the Match statistics
- Winners and Runner-up tracking
- Dynamic charts and visualizations

---

## Tools & Technologies Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Dashboard Design Techniques

---

## Dashboard Insights

The dashboard helps analyze:

- Teams winning after batting first vs fielding first
- Toss decision impact on winning percentage
- Top venues based on matches hosted
- Most successful IPL teams
- Top Player of the Match award winners
